Races: hungary-2022 (Era 10); bahrain-2021, france-2021, russia-2021, turkey-2021,
abu-dhabi-2021 (Era 9); germany-2018, germany-2019, hungary-2019, brazil-2019 (Era 8).
Five are shared with Daily (bahrain-2021, france-2021, russia-2021, abu-dhabi-2021,
hungary-2019): their Daily files and hashes are unchanged, and their Eras content is in
`data/eras/<id>.json` only.

Every fact below was read in the linked source on Nov 8 2026. Headlines are original wording.
No team radio is quoted. Check each row, then put your initials and the date in **Owner
checked**.

## How the content was made

- **Side.** `pipeline hard-calls <id>` was run for every race, and the side with more hard calls
  is the Eras side (owner decision Nov 8: also on shared races). Ties went to the side whose
  real calls gave up more chance.
- **Eras-only races on the other side** (hungary-2022, turkey-2021, brazil-2019) were
  re-registered in `pipeline/build.py` (user_side and rival swapped, name reordered), rebuilt,
  and still pass G1 (`pipeline validate`).
- **Shared races on the other side** (france-2021, abu-dhabi-2021) keep their Daily file. Their
  Eras moments are in the overlay's new `decisionMoments` key, and the merge plays the model
  from `eras.userSide`.
- **Moments.** Made with `pnpm --filter @laststint/sim author <id> --eras [--target T] --write`,
  graded on the race's own target where that differs from beating the rival. turkey-2021 also
  has a hand-made `stop-44` (stay out / box), and `pace-41` was dropped so that the bounded
  search reaches the passing path. bahrain-2021, russia-2021 and hungary-2019 keep their Daily
  moments, which are already from the hard-call side.
- **Reachability.** `pnpm --filter @laststint/sim reachability <id>` was run at the era's
  difficulty and at Legend. For a shared race it was run on the file merged with its overlay
  (export.with_eras_fields, the same merge as the Worker). All ten pass: some path earns ★1, ★2,
  ★3 and the hidden objective, and the stay-out path never earns ★3.

## Open points for the owner

1. **Rewrites where the Eras side really won** (hungary-2022, germany-2018, germany-2019,
   abu-dhabi-2021). The hard-call side won the real race, so no result beats history. The rewrite
   condition is set to the target for now. Choose whether these should get a different rewrite.
2. **turkey-2021 `rules.twoCompound: false`**: see that race above.
3. **Grader vs live play**: the grader's playouts don't include live play's incidents, fuel or
   two-compound disqualification, so a call can grade green and still lose in live play
   (turkey-2021 showed it). Not changed here (sim behaviour).
4. **CI reachability doesn't cover shared races**: the CLI reads `data/races/` only, and a shared
   race's file has no `eras` block. Shared races were checked on their merged model by hand.
