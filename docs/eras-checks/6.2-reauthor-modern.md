## What changed in the tools

- **`pipeline hard-calls` counts a shared race on its Eras model.** A Daily/Gauntlet race file has
  no `eras` or `rules` block, so the sim graded it as Daily does (planner continuation, no Eras
  grader). The CLI now merges the race's overlay first (`hard_calls.eras_race_file`, the same
  merge as `build.apply_eras` and the Worker), so the count uses the Eras grader. This is what
  moved three shared races to Hamilton. On the Daily grader the counts are unchanged
  (abu-dhabi-2021 HAM 1 VER 2, france-2021 HAM 1 PER 1, hungary-2019 VER 2 HAM 0). Tests in
  pipeline/tests/test_hard_calls.py.
- **`pnpm author --eras` grades a shared race with its overlay's `eras` / `rules` blocks**, for
  the same reason (packages/sim/scripts/author.ts).
- Registry: eight Eras-only races swapped `user_side` / `rival` (and the name order) in
  pipeline/src/pipeline/build.py, then rebuilt. The swap changes nothing else in the model.

## Open point for the owner: refuelling tanks in authoring and counting

`pauseAt` (moments.ts, used by the hard-call counter and the moment author) starts its run with
`incidents: false`, and the player's tank only burns live (`tankLive`) in live play with
incidents (refuel.ts `initTanks`). So in a refuelling race the counter's and the author's
playouts never run dry: "stay out" at a real stop grades green (japan-2000 stop-22: stay 94%;
san-marino-2005 stop-27: stay 95%), where live play runs dry two laps later. **The reachability
checker and the game grade from live runs, so they are right**; but the hard-call counts of the
refuelling races (japan-2000, france-2004, san-marino-2005, spain-1996, hungary-1998, austria-2002)
come from fuel-blind playouts. Not changed here (it is sim code, and it would change counts of
races another agent is authoring). The fix would be to give the user's car a live tank in
`pauseAt` for an Eras race with refuelling.
