# Step 2.5 track maps: owner sign-off

One row per appendix race. Each track file was built by `pipeline/scripts/eras_tracks.py` (see its
docstring for the four methods). The owner checks each map against an onboard lap of that year
and fills in the last column (date, and pass or what's wrong). Nothing in that column has been
filled in by the build.

What to look at on each map: the shape, the direction of travel (the start line's chequered band
and the car flow), where the start line is, where the pit lane leaves and rejoins, and the corner
numbers. For f1db-drawn layouts the corner numbers are placed automatically at the sharpest bends
of the drawing (the count from f1db), so expect some to be off; stand-in pit lanes run along the
track between hand-set entry and exit points.

Layout-year evidence: f1db records which layout each race used (`circuitLayoutId` in the race
file) and the years each layout ran (comments in the circuit file). A reused outline shares its
source's layout id. Links are pinned to f1db commit `be8174f`.
